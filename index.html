SismoAlert

Sistema inclusivo de detección sísmica con alerta sonora y visual para el hogar.

Integrantes: Zeballos Victoria - Suarez Zaira
Profesor: López Cristian
Curso: 7º 2º

Introducción

Los sismos son eventos naturales e impredecibles que ponen en riesgo la seguridad dentro del hogar. En una emergencia, recibir un aviso temprano es clave para resguardarse. Sin embargo, la mayoría de las alarmas residenciales son solo sonoras, dejando desprotegidas a las personas con discapacidad auditiva o adultos mayores.

Para resolver esta problemática, este proyecto presenta el prototipo de una alarma sísmica inclusiva de bajo costo. Utilizando un microcontrolador y un sensor acelerómetro (MPU-6050), el sistema detecta y analiza las vibraciones de la vivienda. Al confirmar un sismo, activa de manera simultánea una alerta sonora (buzzer) y una alerta visual de alta visibilidad (luces LED), garantizando una advertencia accesible e inmediata para todos los integrantes del hogar.
